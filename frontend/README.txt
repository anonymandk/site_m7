M7 COMMUNITY — FRONTEND PADRONIZADO

Todos os HTML desta pasta carregam:
  m7-community.css

O stylesheet compartilhado padroniza:
- azul elétrico + fundo dark
- tipografia
- header M7 COMMUNITY
- botões
- cards e painéis
- formulários
- footer
- responsividade
- tela de carregamento quando a página já a utiliza

Todos os arquivos estão pensados para ficar diretamente em:
  frontend/

Os links internos devem usar:
  index.html
  login.html
  register.html
  etc.

Não use Jinja/url_for nos HTML estáticos.
